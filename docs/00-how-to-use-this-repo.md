# How to Use This Repository 📚

Welcome to the **System Design Handbook**! This guide is designed to maximize your learning efficiency whether you are preparing for interviews or solving real-world architecture challenges.

---

## 🎯 Navigating the Repository

1. **Start with Fundamentals**: If you are new to distributed systems, read through [**`01-fundamentals`**](01-fundamentals/01-what-is-system-design-and-requirements.md) to build core intuition around availability, latency, and scalability.
2. **Follow a Study Plan**: Pick a tailored timeline from [**`ROADMAP.md`**](../ROADMAP.md) (4-week, 8-week, or 12-week).
3. **Practice Active Recall**: After reading each topic, solve the corresponding exercises in the [**`exercises/`**](../exercises/) directory before checking solutions.
4. **Master the Interview Framework**: Read [**`20-estimation-and-interview-framework`**](20-estimation-and-interview-framework/03-the-6-step-interview-framework.md) to learn how to structure 45-minute technical discussions.
5. **Analyze Real Case Studies**: Study the 35 end-to-end architectures in [**`19-case-studies`**](19-case-studies/01-url-shortener.md).

---

## 📐 Template Standards

Every topic in this repository adheres to strict templates located in [`templates/`](../templates/):
- **Topics**: `templates/topic-template.md` ensures every concept includes trade-offs, real numbers, and interview questions.
- **Case Studies**: `templates/case-study-template.md` structures designs from requirements to capacity estimation, APIs, and deep dives.
- **ADRs**: `templates/adr-template.md` captures real architectural decisions.
